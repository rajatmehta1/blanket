Running AI Agents

How to configure BlanketAudit to use different LLM providers — Groq, OpenAI, Claude, Ollama, Google, or no AI at all.

Quick Start (Pick Your Provider)

The fastest way to get going: set two environment variables and run the scan.

Groq

$0.59 / 1M tokens — cheapest cloud option
1

Get an API key from console.groq.com

2

Set environment variables:

export BLANKETAUDIT_LLM__PROVIDER=groq
export GROQ_API_KEY=gsk_your_key_here
3

Run the scan:

blanketaudit scan ./your-repo --domain healthcare --framework hipaa

Default model: llama-3.1-70b-versatile. Very fast inference, great for iteration.

OpenAI

$0.15–$10 / 1M tokens
1

Get an API key from platform.openai.com

2

Set environment variables:

export BLANKETAUDIT_LLM__PROVIDER=openai
export OPENAI_API_KEY=sk-your_key_here
3

Run the scan:

blanketaudit scan ./your-repo --domain healthcare --framework hipaa

Default model: gpt-4o-mini (cheap). For better compliance analysis, the system auto-upgrades the compliance agent to gpt-4o.

Anthropic (Claude)

$3–$15 / 1M tokens — highest quality
1

Get an API key from console.anthropic.com

2

Set environment variables:

export BLANKETAUDIT_LLM__PROVIDER=anthropic
export ANTHROPIC_API_KEY=sk-ant-your_key_here
3

Run the scan:

blanketaudit scan ./your-repo --domain healthcare --framework hipaa

Default model: claude-sonnet-4-20250514. Compliance agent auto-upgrades to claude-opus-4-20250514 for deeper regulatory analysis.

Ollama (Local & Free)

FREE — runs on your machine
1

Install Ollama from ollama.ai and pull a model:

ollama pull llama3.1
ollama pull nomic-embed-text   # for embeddings (optional)
ollama serve                   # start the server
2

Set environment variables:

export BLANKETAUDIT_LLM__PROVIDER=ollama
export BLANKETAUDIT_EMBEDDING__PROVIDER=ollama
3

Run the scan:

blanketaudit scan ./your-repo --domain healthcare --framework hipaa

No API key needed. Default model: llama3.1. Runs entirely on your hardware — great for air-gapped or privacy-sensitive environments.

Docker shortcut: Run docker compose -f docker-compose.onprem.yml up to get Ollama + the API + Neo4j in one command, zero API keys.

Google Gemini

$0.10–$1.25 / 1M tokens 
export BLANKETAUDIT_LLM__PROVIDER=google
export GOOGLE_API_KEY=your_key_here
blanketaudit scan ./your-repo --domain healthcare --framework hipaa

Default: gemini-2.0-flash. Compliance auto-upgrades to gemini-2.5-pro.

Static Only (No AI)

FREE — no LLM calls 
export BLANKETAUDIT_LLM__PROVIDER=none
blanketaudit scan ./your-repo --domain healthcare --framework hipaa

Uses only Semgrep, Gitleaks, and OSV-Scanner. No AI reasoning, no API keys, completely free. Good for CI/CD gating.

Configuration Methods

Three ways to configure the system (highest priority wins):

1. Environment Variables (Recommended for Quick Use)

All settings use the BLANKETAUDIT_ prefix. Use __ (double underscore) for nested values.

# Provider & model
export BLANKETAUDIT_LLM__PROVIDER=openai
export BLANKETAUDIT_LLM__MODEL=gpt-4o-mini
export BLANKETAUDIT_LLM__COMPLIANCE_MODEL=gpt-4o
export OPENAI_API_KEY=sk-...

# Cost controls
export BLANKETAUDIT_COST__MAX_SCAN_COST_USD=10.00
export BLANKETAUDIT_COST__PER_AGENT_TOKEN_BUDGET=500000

# Embeddings (optional)
export BLANKETAUDIT_EMBEDDING__PROVIDER=openai
export BLANKETAUDIT_EMBEDDING__MODEL=text-embedding-3-small

2. audit.yaml Config File (Recommended for Projects)

Create an audit.yaml in your project root:

# audit.yaml
scan:
  repos:
    - url: github.com/myorg/api-service
      branch: main
    - url: github.com/myorg/payment-service
      branch: main

frameworks: [hipaa, soc2]
domain: healthcare

llm:
  provider: anthropic
  model: ""                        # empty = auto-select per provider
  compliance_model: ""             # auto-selects higher-capability model
  temperature: 0.0
  agent_model_overrides:          # optional: per-agent model routing
    compliance: claude-opus-4-20250514
    security: claude-sonnet-4-20250514

cost:
  max_scan_cost_usd: 15.00
  per_agent_token_budget: 500000
  abort_on_budget: true

output:
  formats: [pdf, json]
  path: ./audit-report
  min_severity: low

Then run: blanketaudit scan --config audit.yaml

3. CLI Flags (Highest Priority)

blanketaudit scan ./repo \
  --domain healthcare \
  --framework hipaa \
  --framework soc2 \
  --format pdf \
  --format json \
  --output ./reports \
  --name "My Project" \
  --max-cost 10.0
Precedence: CLI flags > environment variables > audit.yaml > defaults. So you can set your provider in audit.yaml and override the cost limit on the command line.

Per-Agent Model Routing

Different agents can use different models. The compliance agent often needs a more powerful (and expensive) model for regulatory reasoning.

How the System Picks a Model

# Resolution order (first match wins):
1. agent_model_overrides.agent_name   # explicit per-agent override
2. compliance_model                    # if agent is "compliance"
3. Provider default for compliance     # e.g., claude-opus for anthropic
4. model                               # the standard model setting
5. Provider default                    # e.g., claude-sonnet for anthropic

Example: Mix Cheap & Powerful

# audit.yaml — use cheap model for most agents, powerful for compliance
llm:
  provider: anthropic
  model: claude-sonnet-4-20250514        # $3/1M — used by security, architecture, quality
  compliance_model: claude-opus-4-20250514  # $15/1M — only used by compliance agent
# Or go fully granular:
llm:
  provider: openai
  agent_model_overrides:
    compliance: gpt-4o              # most capable, for regulations
    security: gpt-4o-mini           # good enough for vuln analysis
    architecture: gpt-4o-mini
    quality: gpt-4o-mini

Cost Controls

Every scan has built-in cost protection. Here's how to control spending:

Dry Run (Estimate Before Spending)

blanketaudit scan ./your-repo --dry-run

This scans and triages all files, then shows the estimated cost without making any LLM calls. Output includes:

  • Total estimated USD
  • Per-agent token and cost breakdown
  • File tier distribution (how many files get full AI vs. static-only)
  • Model routing (which model each agent will use)

Budget Limits

SettingDefaultWhat It Does
max_scan_cost_usd$15.00Hard limit per scan. Aborts if exceeded.
per_agent_token_budget500,000Token limit per agent. At 80% → demotes remaining files to static-only. At 100% → stops LLM calls.
abort_on_budgettrueWhether to abort or continue with static-only when budget is hit.
require_dry_runfalseForce a dry-run estimate before every scan.
# Set a tight budget via env vars
export BLANKETAUDIT_COST__MAX_SCAN_COST_USD=5.00
export BLANKETAUDIT_COST__PER_AGENT_TOKEN_BUDGET=200000

# Or via CLI flag
blanketaudit scan ./repo --max-cost 5.0
Budget safety: If an agent hits its token budget, it automatically falls back to static-only analysis for remaining files. The scan still completes — you just get less AI reasoning on lower-priority files.

How the 4 Agents Use the LLM

Each agent follows the same pattern: static tools first, then AI reasoning. If the LLM is unavailable, agents fall back to static-only.

AgentStatic ToolsAI DoesRecommended Model
Security Semgrep, Gitleaks, OSV Filters false positives, assesses exploitability, computes blast radius Standard (Sonnet / GPT-4o-mini)
Compliance Policy rules, Milvus RAG search Maps code patterns to regulatory controls, assesses PASS/FAIL High-capability (Opus / GPT-4o)
Architecture Dep graph, call graph, topology Detects design violations, coupling, circular deps, SPOFs Standard (Sonnet / GPT-4o-mini)
Quality Complexity metrics, coverage parser Identifies maintainability issues, dead code, tech debt patterns Standard (Sonnet / GPT-4o-mini)
Why compliance needs a stronger model: Regulatory reasoning requires understanding legal language, mapping code patterns to specific control clauses (e.g., HIPAA §164.312), and making nuanced PASS/PARTIAL/FAIL judgments. The other agents work well with standard models.

Troubleshooting

ProblemFix
Scan runs but no AI findingsCheck blanketaudit providers --check to verify your API key works.
"BudgetExceededError" mid-scanIncrease BLANKETAUDIT_COST__MAX_SCAN_COST_USD or use a cheaper model.
Ollama connection refusedMake sure ollama serve is running on port 11434.
Slow Ollama performanceUse a smaller model (llama3.1:8b instead of 70b), or ensure GPU acceleration is enabled.
Rate limit errors (429)The system auto-retries 3 times with exponential backoff. If persistent, reduce per_agent_token_budget.
Circuit breaker tripped5 LLM failures in 60s triggers the breaker. It auto-recovers after 120s. Check API key and provider status.
Only static findings, no AI analysisProvider is set to none, or the circuit breaker tripped. Check BLANKETAUDIT_LLM__PROVIDER.
