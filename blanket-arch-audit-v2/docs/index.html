How It Works

Tier Stage What Happens
1 Source Input Clone from GitHub, GitLab, Bitbucket, or scan a local directory
2 Ingestion Tree-sitter AST parsing, dependency graph, manifest extraction
2.5 Entity Extraction Classes, methods, calls, entry points; method-level call graph in Neo4j
3 Orchestration LangGraph pipeline: triage files, estimate cost, dispatch agents
4 AI Analysis 4 parallel agents: Security, Compliance, Architecture, Quality
5 Scoring Dedup, 4 hallucination gates, 8-category risk scoring, roadmap
6 Report PDF (dark theme), HTML (interactive), JSON, SARIF
7 Delivery Local filesystem, webhooks, SQLite scan history
