Future Features Roadmap 2026

Where BlanketAudit is headed. These features are organized into 30/60/90 day phases, from quick wins that ship fast to moonshots that redefine what an audit tool can do.

Phase 1: Next 30 Days quick wins

High-impact features that build on existing infrastructure. Each can ship independently.

1. Auto-Fix PR Generation

Every finding already includes fix_code with before/after snippets. This feature closes the loop: BlanketAudit creates a branch, applies the fix, and opens a pull request on GitHub/GitLab with the finding ID as the title and the AI explanation as the PR body. One-click remediation from the report to a merged fix.

Effort2 weeks (1 engineer)
ImpactReduces mean time to remediate from days to minutes. Transforms BlanketAudit from "tells you what's wrong" to "fixes it for you."

2. Slack & Microsoft Teams Integration

Post scan summaries to a channel when a scan completes. Alert on new critical findings compared to the previous scan. Send a daily compliance digest showing controls that moved between PASS, PARTIAL, and FAIL. Configurable via webhook URL in audit.yaml.

Effort1 week
ImpactKeeps security and compliance teams informed without logging into a dashboard. Critical for enterprise adoption where Slack is the nervous system.

3. VS Code Extension

Show BlanketAudit findings inline in the editor. Red underlines on vulnerable lines with severity-colored squiggles. Hover over a finding to see the AI explanation, blast radius, and compliance refs. Quick-fix code action applies the fix_code directly. Reads from report.sarif so it works with any scan.

Effort3 weeks
ImpactBrings findings to where developers already work. SARIF integration means it also works with GitHub Codespaces and other SARIF-compatible editors.

4. GitHub App (PR Gating)

Install as a GitHub App. Automatically scan every pull request. Post SARIF results as inline code review comments on the exact lines with findings. Block merge if any critical-severity findings are detected. Configuration lives in .blanketaudit.yml at the repo root.

Effort2 weeks
ImpactShifts security left into the PR workflow. Prevents vulnerabilities from reaching main. The single most requested feature for CI/CD teams.

Phase 2: Next 60 Days differentiators

Features that separate BlanketAudit from every other SAST tool on the market.

5. AI Agent Memory & Learning

Agents build a persistent knowledge base about your codebase over repeated scans. Custom patterns are learned: if you consistently mark a finding as a false positive, the agent adjusts its confidence threshold for that pattern. Over time, BlanketAudit generates custom policy rules tailored to your codebase's conventions. False positive rate drops with each scan.

Effort4 weeks
ImpactSolves the #1 complaint with SAST tools: noise. A tool that gets smarter about YOUR code is exponentially more valuable than one that treats every repo the same.

6. Dependency License Audit & SBOM

Flag GPL-licensed dependencies in commercial projects. Generate Software Bill of Materials in CycloneDX and SPDX formats. Build a license compatibility matrix that shows which dependencies conflict with your project's license. Integrates with the existing manifest parser to pull license data from npm, PyPI, Maven Central, and crates.io.

Effort3 weeks
ImpactSBOM generation is becoming a regulatory requirement (US Executive Order 14028). This makes BlanketAudit essential for government contractors and enterprise procurement.

7. Secret Rotation Automation

When Gitleaks detects a hardcoded secret, BlanketAudit goes beyond alerting. It identifies the secret type (AWS key, database password, API token), rotates it via the provider's API (AWS Secrets Manager, HashiCorp Vault, GCP Secret Manager), updates the code to reference an environment variable, and opens a PR with the change. The old secret is invalidated automatically.

Effort4 weeks
ImpactHardcoded secrets are the most common critical finding. Auto-rotation eliminates the most dangerous class of vulnerability without human intervention.

8. Compliance Certification Tracker

Track SOC 2, HIPAA, and PCI-DSS compliance progress over time with a dedicated dashboard. See controls moving from FAIL to PARTIAL to PASS across scans. Timeline view shows when each control was last assessed and its trend. Generate auditor-ready evidence exports with timestamps, scan IDs, and remediation history. Answers the auditor's question: "Show me when you fixed this and prove it stayed fixed."

Effort3 weeks
ImpactTurns BlanketAudit from a point-in-time scanner into a continuous compliance platform. Companies preparing for SOC 2 audits will use this daily.

9. Multi-Language Deep Analysis

Expand entity extraction and call graph construction to Go, Rust, C#, and Kotlin. Deeper call graph resolution with generic type support, trait/interface dispatch, and async call tracking. The existing Tree-sitter infrastructure handles parsing; this work focuses on language-specific extractors and symbol resolution for each language's type system.

Effort6 weeks (across all 4 languages)
ImpactUnlocks enterprise adoption where codebases span multiple languages. Go and Rust are particularly high-demand given the cloud-native ecosystem.

Phase 3: Next 90 Days moonshots

Ambitious features that push the boundary of what automated code audit can achieve.

10. Runtime Taint Analysis

Instrument a running application to trace actual data flows at runtime. Compare static analysis predictions (the call graph's taint paths) against real observed data movement. When static analysis says "user input reaches this SQL query," runtime analysis confirms or refutes it with actual execution traces. This eliminates false positives on taint paths entirely and provides concrete proof of exploitability.

Effort8 weeks
ImpactZero false positives on taint-based findings. This is the holy grail of application security: combining static and dynamic analysis into one workflow.

11. AI Architecture Advisor

Ask natural language questions about your architecture: "Should I split this monolith into microservices?" "Is PostgreSQL the right database for my access patterns?" "What happens if this service goes down?" The advisor uses the call graph, dependency analysis, and traffic patterns to generate evidence-based architecture recommendations with trade-off analysis. Not opinions—data-driven advice grounded in your actual codebase.

Effort6 weeks
ImpactReplaces expensive architecture consulting engagements. A staff engineer in a box that knows your entire codebase.

12. Compliance Evidence Generator

Auto-generate SOC 2 evidence packets from scan results. Map findings directly to specific auditor questions from the AICPA Trust Services Criteria. Generate a complete evidence binder with: control descriptions, test procedures, test results, exception tracking, and remediation evidence. Exportable as a structured PDF that auditors can review directly, cutting weeks off the audit preparation process.

Effort5 weeks
ImpactSOC 2 audit preparation costs $50K-$200K in consulting fees. This feature pays for itself on the first audit cycle.

13. Threat Modeling Agent

Perform automated STRIDE threat analysis per API endpoint. Generate attack trees showing how an attacker could chain vulnerabilities. "If an attacker compromises the auth service, here is every piece of data they can reach, every service they can pivot to, and every user population affected." Uses the call graph's cross-repo edges and blast radius data to map realistic attack paths, not theoretical ones.

Effort6 weeks
ImpactThreat modeling is required by many compliance frameworks but rarely done because it is expensive and manual. Automation makes it accessible to every team.

14. Cross-Organization Benchmarking

Opt-in anonymous benchmarking: "Your healthcare application scores 31. The median healthcare application on BlanketAudit scores 58. You are in the bottom 15th percentile for HIPAA compliance." No code is shared—only aggregate scores, finding category distributions, and anonymized trends. Industry-specific benchmarks for healthcare, fintech, e-commerce, and SaaS verticals.

Effort4 weeks
ImpactCreates a powerful network effect. The more companies use BlanketAudit, the more valuable the benchmarks become. Also creates urgency: "We are below the industry median" drives executive buy-in for remediation.

15. Natural Language Audit Queries

Chat with your codebase using natural language. "Show me all endpoints that access PHI without encryption." "Which services have no authentication middleware?" "What is the blast radius if the payment database is compromised?" Queries execute against the code graph (Neo4j) and vector database (Milvus) simultaneously, combining structural and semantic search. Results are returned as interactive finding cards with evidence and code snippets.

Effort5 weeks
ImpactTransforms BlanketAudit from a batch scanning tool into an interactive security research platform. Security teams can investigate hypotheses in seconds instead of hours of manual code review.
